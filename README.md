# 🌾 Análise de Vendas Agrícolas da Fazenda Bela Vista (BD Fazenda)

Este repositório contém o projeto final desenvolvido para o curso presencial de Banco de Dados para Data Science realizado no SENAI Guarulhos. 
O objetivo do projeto foi construir um pipeline de dados completo para analisar a produção e as vendas de três produtos agrícolas de uma fazenda.

## 🎯 Objetivo do Projeto
Extrair dados de produção e comercialização do banco de dados `BD Fazenda`, tratá-los via script e criar um painel gerencial que facilite a tomada de decisão sobre o desempenho dos três principais produtos da safra: **[Produto A]**, **[Produto B]** e **[Produto C]**.

## 🛠️ Tecnologias e Fluxo de Trabalho
1. **SQL Server:** Construção das queries complexas para extração e estruturação da base de dados `BD Fazenda`.
2. **Python:** Conexão direta com o banco de dados e manipulação/tratamento dos dados utilizando bibliotecas como `pandas`.
3. **Power BI:** Desenvolvimento de um Dashboard interativo para visualização das métricas de colheita, volume de vendas e faturamento.

## 📂 Estrutura do Repositório
* `consulta_bdfazenda.sql`: Script com as consultas elaboradas no SQL Server.
* `conexao_tratamento.ipynb`: Notebook em Python realizando a integração e limpeza da base.
* `dashboard_fazenda.pbix`: Arquivo do Power BI com o painel final.
* `print_dashboard.png`: Imagem do dashboard finalizado.
